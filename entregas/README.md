# Entregas

Esta pasta guarda as entregas dos trainees. Cada aluno tem a **sua própria pasta**, nomeada igual à sua branch (`nome-sobrenome`), e dentro dela uma subpasta por semana.

```
entregas/
└── seu-nome-sobrenome/
    ├── README.md
    └── semana-00/
        ├── README.md
        └── hello.py
```

## Regras

- **Nunca apague o material do repositório** — você só adiciona arquivos na sua pasta aqui.
- Nomeie a pasta com o mesmo padrão da sua branch: `nome-sobrenome`.
- Uma subpasta por semana: `semana-00`, `semana-01`, ..., `semana-08`.
- Cada pasta de semana precisa de um `README.md`.

O passo a passo completo (primeira semana e rotina das próximas) está no [Padrão de Entregas](../docs/padrao-entregas.md).

O progresso de todos fica em [docs/status.md](../docs/status.md), gerado por `scripts/gerar-status.py`.
