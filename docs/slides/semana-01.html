O Dataset

Arquivo entregas/dados/semana-01/cleaned.csv - cada linha é um pacote enviado pela serial.

  • Não tem cabeçalho (primeira linha já é dado)
  • Cada linha começa com o prefixo #51 (o ID do pacote)
  • 24 campos separados por vírgula
#51,2003976,34647,39.53,42.34,0.00,957.29,1.87,0.26,-0.34,-39.20,-0.82,2.53,0.00,39.53,2,0,2000,487.80,-21.942293,-48.951912,12,0,-121

Os 24 Campos

ID, millis, pckt, alt, temp, humi, press,
gx, gy, gz, ax, ay, az, vz, maxalt, state,
hora, data, gps_alt, lat, lon, sat, pqd, rssi
  • alt - altitude (m)  ·  temp - temperatura (°C)
  • press - pressão (hPa)  ·  lat/lon - GPS
  • millis - tempo em ms  ·  rssi - sinal recebido (dBm)

Lendo com pandas

Como o arquivo não tem cabeçalho, passamos os nomes das colunas:

import pandas as pd

COLUNAS = [
    "ID", "millis", "pckt", "alt", "temp", "humi", "press",
    "gx", "gy", "gz", "ax", "ay", "az", "vz", "maxalt", "state",
    "hora", "data", "gps_alt", "lat", "lon", "sat", "pqd", "rssi",
]

def ler_csv(caminho):
    df = pd.read_csv(caminho, header=None, names=COLUNAS)
    df["ID"] = df["ID"].astype(str).str.lstrip("#").astype(int)
    return df

O # do ID é removido para virar número.

Alternativa: csv padrão

import csv

def ler_csv(caminho):
    linhas = []
    with open(caminho) as f:
        for linha in csv.reader(f):
            linha[0] = linha[0].lstrip("#")   # tira o # do ID
            linhas.append([float(v) for v in linha])
    return linhas

Sem cabeçalho, então usamos csv.reader, não DictReader.

Calculando Estatísticas

def calcular_estatisticas(df, campo):
    serie = pd.to_numeric(df[campo], errors="coerce").dropna()
    return {
        "media": serie.mean(),
        "maximo": serie.max(),
        "minimo": serie.min(),
        "amostras": len(serie),
    }

stats = calcular_estatisticas(df, "alt")
print(f"Altitude media: {stats['media']:.2f} m")
print(f"Max: {stats['maximo']:.2f} m")
print(f"Min: {stats['minimo']:.2f} m")

Sempre valide se a série não está vazia antes de usar a média!

Salvando Resumo em Arquivo

def salvar_resumo(estats, nome_arquivo="resumo.txt"):
    with open(nome_arquivo, "w") as f:
        f.write("=== RESUMO DE TELEMETRIA ===\n\n")
        for e in estats:
            f.write(f"{e['campo']}:\n")
            f.write(f"  Media:    {e['media']:.2f}\n")
            f.write(f"  Max:      {e['maximo']:.2f}\n")
            f.write(f"  Min:      {e['minimo']:.2f}\n")
            f.write(f"  Amostras: {e['amostras']}\n\n")
    print(f"Resumo salvo em {nome_arquivo}")

matplotlib — Primeiro Gráfico

import matplotlib.pyplot as plt

def plotar_altitude(df):
    tempo_s = (df["millis"] - df["millis"].min()) / 1000
    plt.figure(figsize=(10, 5))
    plt.plot(tempo_s, df["alt"], color="#ff6b35", linewidth=2)
    plt.title("Altitude vs Tempo")
    plt.xlabel("Tempo (s)")
    plt.ylabel("Altitude (m)")
    plt.grid(True, alpha=0.3)
    plt.tight_layout()
    plt.savefig("altitude.png", dpi=150)
    plt.show()

Tratamento de Erros

Sempre considere que o arquivo pode estar ausente:

from pathlib import Path
import sys

def main():
    if len(sys.argv) < 2:
        print("Uso: python leitor.py <arquivo.csv>")
        return

    caminho = sys.argv[1]
    if not Path(caminho).exists():
        print(f"Erro: arquivo {caminho} nao encontrado")
        return

    df = ler_csv(caminho)
    if df.empty:
        print("CSV vazio - nada a analisar")
        return
